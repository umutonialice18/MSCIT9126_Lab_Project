\# Security Policy



\## Purpose



This document defines security practices used in the MSCIT9126 Lab Project.



\## Security Measures



\- Use SSH authentication for GitHub access.

\- Enable Two-Factor Authentication (2FA).

\- Protect sensitive information such as passwords and API keys.

\- Apply firewall rules to control network access.

\- Maintain regular configuration backups.



\## Access Control



Only authorized users should access the lab environment and repository.



\## Data Protection



Sensitive files must not be uploaded to the public repository.
